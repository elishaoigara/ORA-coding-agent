# UI inspection findings

The deployed app at https://ora-coding-agent.vercel.app/ uses a three-column layout with a narrow history sidebar, central chat area, and GitHub sidebar. The screenshot and live inspection show a light beige/white visual system with low contrast and a compact header.

The model selector opens a tall menu that expands into the central workspace and visually competes with the GitHub sidebar. At the screenshot viewport, the GitHub panel overlays the right portion of the model list, making provider/model choices difficult to read and select. The live menu exposes provider groups, models, system prompt controls, and custom instructions in one tall popover.

The main visual issues are: the model popover has insufficient z-index/isolation relative to the GitHub panel; the selector is too narrow for model names; the menu is not a contained, scrollable command surface; the header controls are cramped; the overall typography and borders feel generic; the app has too little visual hierarchy between navigation, workspace, and tools; and the center empty state does not communicate an advanced coding-agent workflow.

The redesign should use a dark futuristic workspace, stronger typography, contained panels, a dedicated model command palette/popover with its own stacking context and internal scroll, clearer active states, and responsive behavior that turns sidebars into overlays on smaller widths.

## Live verification

After deployment, the futuristic shell is visible with the cyan/violet ORA mark, mono kicker, darker grid-backed workspace, improved prompt cards, and stronger panel separation. Opening the model trigger now renders a contained `MODEL ROUTER` palette above the GitHub rail with an internal scroll region and readable provider/model rows. The model list is no longer hidden behind the GitHub panel in the live viewport.
